# Experimental three-pathway assessment (draft)

- `index.html`: existing Version 13 infrastructure assessment, with new pathway navigation.
- `data.html`: draft Data & Datasets assessment.
- `resources.html`: draft Tools & Interoperability Resources assessment.
- `data-questions.json`, `resources-questions.json`: editable question sets.
- `assessment-app.js`: independent local drafts and JSON/PDF ZIP exports.

Upload the **contents** of this ZIP to the root of the `experimental` branch. Do not modify `main`. The experimental branch intentionally contains no `.github/workflows/pages.yml`: the existing workflow on `main` publishes both branches. After committing the files, manually run the Pages workflow from `main`.

This is a first prototype. Test PDF/JSON exports and mobile navigation before collecting real responses.
